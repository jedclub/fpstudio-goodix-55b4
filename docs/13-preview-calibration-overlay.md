# 배경 보정·손 뗌 감지와 매칭 영역 표시

## 확인된 문제

2026-09-07 `live-20260907-020714-076`에서 UI는 2,610프레임을 받고
접촉을1회로 집계했다. 사용자는 실제로 여러 번 완전히 떼었다 다시 대고,
살짝 끌기도 했다고 확인했다. **해당 접촉 집계는 잘못됐다.**
3회 비교 뒤 추가 시도가 진행되지 않은 것은 재접촉이 새 그룹으로 잡히지
않은 결과다. 같은 세션의 색감/무늬도 이전과 다르게 보였다고 확인했다.

남아 있는 마지막 약29초의553개 신호는 원본-배경 평균 절대차165.9~821.7로,
기존 기준100 미만이 전혀 없었다. 이 로그만으로 전체 밝기 드리프트인지
초기 배경에 지문이 들어갔는지는 구분할 수 없다. 기존 프리뷰는 초기 한 장을
배경으로 사용했고, 일반 캡처 경로의 배경 재시도도 우회했다.

## 실험 드라이버 수정0017

시스템 인증 경로는 변경하지 않는다. `GOODIX55X4_PREVIEW_PATH`로 요청한
로컬 연구 스트림에만 아래 동작이 적용된다.

- 첫20프레임은 안정화 대기. 이어 프레임 간 공간적 변화가20 이하인40프레임을
  평균해 배경을 수집한다. 불안정하면 수집을 다시 시작한다.
- 이 동안 GUI는 접촉을 요청하지 않고, 후보 저장/매칭을 하지 않는다.
- **안정된 영상이라는 사실만으로 손이 없음을 입증할 수는 없다.** 사용자가
  안내대로 센서를 비워야 하며, 최초 보정의 하드웨어 부재 판정은 아직 없다.
- 손가락 신호는 `(현재-배경)`에서 전체 평균 밝기 차이를 제외한 평균 절대
  잔차를 사용한다. 원본 평균 절대차도 별도로 보고한다.
- 접촉 시작은 max(40, 잡음×8) 이상3프레임, 손 뗌은 max(20, 잡음×4)
  이하3프레임이다. 이는 실험용 초기값이며 실제 센서 반복 검증이 필요하다.
- 접촉 중 배경을 자동 학습하지 않는다. 이번 변경은 밝기 차이를 손가락으로
  오인하는 경우를 분리하기 위한 것이지 센서의 모든 드리프트를 해결한 것은 아니다.
- 원본12비트 최신 영상 `live.pgm.raw.pgm`과 수집 배경
  `live.pgm.background.pgm`을0600으로 남긴다. 원본은 최신 한 장으로 교체한다.
  화면 영상의 기존 배경 절대차/명암 정규화는 유지한다. 색감 변화 자체는
  지문 변화의 증명이 아니며 원본/배경을 함께 분석해야 한다.
- PGM 메타데이터는 timestamp, centered_signal, coverage, sharpness,
  raw_difference, background_ready, contact_on, noise 순서다.

0016 위에 `patches/0017-preview-multiframe-background-and-presence.patch`를
적용하고 로컬 라이브러리를 빌드한다. PKGBUILD의 일반 시스템 설치 경로에는
이번 프리뷰 패치를 추가하지 않았다. 테스트용 C 상태 계산 원본은
`src/driver/experimental/preview_state.h`에 보존하며 패치 속 헤더와 동일해야 한다.

## 비교 영역 표시

Vulkan 탐색 후 원본 내부 영역 검증에서 informative/supported16비트 마스크를
함께 반환한다. UI는 실제 비교에 사용한 불변 gpu-probe 영상 위에 표시한다.

- 초록: 국소 명암·방향 기준을 함께 지지한 영역
- 빨강: 정보가 있는 영역이지만 지지 기준에 미달한 영역
- 색칠 없음: 검증 정보가 부족한 영역
- 파란 테두리: 선택된 회전/이동/배율로 옮긴 기준 영상의 내부 비교 범위

색상은 실제 정렬 좌표에 적용하고 검사 영상의 내부 영역으로 잘라 표시한다.
실시간 영상과 별도로, **비교 당시 정지 영상**이라는 문구와 접촉/요청 번호를
붙인다. 현재 움직이는 영상에 이전 정렬을 잘못 덧씌우지 않는다.
`gpu-overlay-NNNN.png`도0600으로 저장한다. 초록 영역이 신원 인증 승인을
뜻하지 않으며 빨강도 다른 손가락임을 증명하지 않는다.

## 검증 범위

- 실제 C 상태 계산으로 전체 밝기+200 변화에 접촉 오인 없음,
  무늬 추가/제거10회에 접촉/손 뗌 분리, 배경 고정 유지 시험
- 새 메타데이터 형식에서 원본 차이220인 손 뗌도 올바르게 처리하는 UI 시험
- 실제 Vulkan 결과의 영역 마스크와 초록색 오버레이 파일 생성 시험
- 기존 회전·배율·CPU/GPU 수치 일치·중복 실행·대기열·중단 회귀 시험

자동 시험은 실제 손 뗌 반복 검증을 대체하지 않는다. PAM, fprintd,
시스템 등록 지문에는 이번 연구 변경을 반영하지 않는다.
