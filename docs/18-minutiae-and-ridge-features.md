# 표준 minutiae와 작은 영역 센서의 특징 선택

## 표준과 현재 센서의 차이

지문 minutiae 상호운용 형식은 ISO/IEC 19794-2 및 ANSI/INCITS 378 계열이다.
일반적인 핵심 점은 융선 끝점과 분기점이며, 위치와 방향을 함께 기록한다.
NIST의 표준 안내도 세선화된 골격에서 융선 끝점/분기점을 배치하고 방향을
구하는 방법을 설명한다. 복잡한 모양은 끝점·분기점 조합으로 표현한다.

- [NIST Quick Minutiae Search Profile](https://tsapps.nist.gov/trainingtool/FundamentalAFISSearching/MarkingMinutiae.html)
- [NIST MINEX API: ANSI/INCITS 378 minutiae extraction](https://www.nist.gov/document/minex04apipdf)

하지만 이 Goodix 장치는 108×88픽셀의 작은 부분만 얻는다. 실제 프리뷰에는
거의 평행한 능선 조각이 주로 보이며, 영상 끝에서 끊긴 선은 손가락의 진짜
끝점이 아니다. 그런 경계 특징을 템플릿으로 쓰면 손가락 위치가 약간 바뀔 때
마다 가짜 minutiae가 생겨 오히려 FRR/FAR를 해친다.

## 연구용 minutiae 파이프라인

`tools/vkmatch/minutiae.h`는 인증 결정과 분리된 연구 파이프라인이다.

1. 11×11 국소 임계값으로 어두운 능선 후보를 만든다.
2. Zhang–Suen 세선화로 1픽셀 골격을 만든다.
3. crossing-number 1/3으로 끝점과 분기점 후보를 만든다.
4. 바깥 12픽셀을 버리고, 능선 방향 일관성·국소 대비가 낮은 후보와 반경
   4.5픽셀 안의 중복 후보를 제거한다.
5. GPU가 이미 찾은 회전·이동·균일 크기 변환으로 내부 minutiae를 일대일
   기하 매칭한다. 타입 일치는 참고 정보일 뿐 필수 조건이 아니다.

경계 제외와 내부 Y-분기점 보존, 동일 기하 변환의 일관성은
`minutiae-interior-controls` 회귀 시험으로 검사한다. 결과 JSON에는 개수·쌍 수·
방향 합의율만 남기며 좌표나 지문 영상은 로그에 남기지 않는다.

이 기능은 `research-v1-not-an-authentication-gate`다. sudo/KDE/PAM 정책은
바꾸지 않았고, minutiae만으로 인증 허용 또는 거부하지 않는다.

## 실제 자료의 결론

기준 세션 25장과 최신 `063446` 세션의 14개 검사 영상에서 이 파이프라인을
읽기 전용으로 평가했다. 검사 영상 중 내부 특징점이 3개 이상인 것은 7/14,
GPU 정렬 뒤 minutiae 기하 조건까지 일관된 것은 1/14였다. 반면 기존 내부
능선 영상 증거는 14/14 일관됐다.

따라서 이 해상도·캡처 범위에서 표준 minutiae를 지금 당장 강제 관문으로 넣으면
동일 손가락 거절이 급증한다. minutiae는 영상 품질 진단과 더 넓은 캡처가 가능한
후속 장치의 상호운용 템플릿 경로로 보존한다.

현재 주 인증 연구 방향은 내부 능선 조각의 **방향·위상·국소 고유성**이다.
v7은 먼저 접촉영역과 검은 보정 배경을 0/1로 분리하고, 두 접촉영역의 교집합에서
4×4 내부 타일의 명암/방향 합의와 공간 분포를 검사한다. 이 분할의 상세와
0/1 분할의 고정 자료 재생 결과는 [19-ridge-roi-v7.md](19-ridge-roi-v7.md)에 있고,
그 접촉영역을 매 비교의 회전 피벗/앵커로 쓰는 v8 변경과 재생 결과는
[20-contact-anchored-rotation-v8.md](20-contact-anchored-rotation-v8.md)에 있다.
minutiae 결과가 충분히 안정적이라는 측정이 나올 때까지 minutiae 자체는 인증
정책에 넣지 않는다.

## ±5% 균일 크기 탐색

인증 후보 탐색은 균일 크기 0.95~1.05만 허용한다. 초기 GPU 배치는
0.95, 0.97, 0.975, 1.00, 1.025, 1.03, 1.05를 검사하고, 실패 후보만 같은
범위 안에서 정밀 위치·회전·크기 탐색을 한다. 가로·세로 비율을 따로 바꾸거나
국소 탄성 변형을 하지 않는다.

기존 v6 실패 19개를 이 범위로 재검사했을 때 추가 회복은 0개였다. 이는
크기 변화가 현 실패의 주원인이 아님을 보여 준다. 기존 0.97/1.00/1.03
후보는 새 격자에도 보존하므로 범위 확대가 이전 가설을 삭제하지 않는다.
이 결과는 반복한 동일 손가락 개발 자료이며, 타인 지문 FAR 검증은 아니다.
