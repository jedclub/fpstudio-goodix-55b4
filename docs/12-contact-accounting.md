# 접촉 누락 방지와 자동 재비교 (2026-09-07)

## 이번 수정

기존 LiveWindow는 `m_touch <= 30` 뒤 후보 수집을 중단했고, GPU가 초기화/계산
중이면 matchFrame에서 후보를 버렸다. 최신 실제 세션의 감지65접촉 중29접촉만
비교됐기 때문에28/29를 전체 성공률로 해석할 수 없었다.

- 후보 저장 상한을 감지 접촉 번호가 아니라 **저장 후보 수128장**에 적용한다.
- 초기화/계산 중 접촉별 최신 최고 후보1장을 대기시킨다. 원래 접촉 ID와
  센서 타임스탬프를 함께 전달하며, GPU는 여전히 한 요청씩 처리한다.
- 한 접촉의 내부 일관성이 미달이면, 기존 품질 기준을 통과하면서 앞서 제출한
  영상과 평균 픽셀 차이4 이상인 다른 영상을 자동 재비교한다. 품질/매칭 기준은
  낮추지 않는다. 접촉당 최대3회, 전체384회이며 GPU 결과에 selection_kind를 기록한다.
- 자연 종료 때는 남은 비교를 마친다. 사용자 중단은 대기/진행 중 비교도 취소하고
  취소 사유를 남긴다. 초기화/개별 계산에는30초 제한이 있다.
- live-status.json schema_version2에는 종료 후에도 전체 감지 접촉, 후보,
  비교 완료 접촉, 내부 일관성 접촉, 미비교 접촉, 품질/오류/한도/취소 사유를 보존한다.
  접촉은 센서 신호로 추정한 그룹이며 물리적인 손가락 접촉의 정답 라벨이 아니다.
- 안내는 면적 부족/움직임/무늬 부족/비교 대기/일관성 확인/재접촉으로 분기한다.
  기본 안내는 사용자가 확인한 **같은 손가락**이며 특정 손가락 위치를 추정하지 않는다.
- GUI/MCP/센서 세션의 기존 중복 실행 잠금, 중단 버튼 하나, 비공개 저장은 유지한다.

평가 분모는 선별된 영상뿐 아니라 감지된 접촉 전체를 함께 보고해야 한다.
consistent는 여전히 연구용 영상 내부 무늬 일관성이며 신원 인증 판정은 null이다.

## 자동 시험

실제 USB를 열지 않는 가짜 센서·지연 작업자로 다음을 검증한다.

- 감지33접촉 중 품질 미달1접촉과 비교 가능한32접촉을 모두 집계
- 초기화2초, 요청450ms 지연 상태에서30번째 이후 접촉도 처리
- 원래 접촉 ID/타임스탬프와 비공개 결과 파일 권한 유지
- 자연 종료 뒤 대기열 처리, 사용자 중단 시 취소 사유, 실행 불가능 작업자
- 같은 접촉에서 영상 변화가 생겼을 때3회 이내 자동 재비교

실제 Vulkan CPU 수치 일치, 회전 정렬, UI 연결, GUI/MCP 중복 실행 시험도 유지한다.
가짜 작업자의 일관성 결과는 UI 상태 시험용이며 생체 인식의 증거가 아니다.

## 크기 변화 탐색 실험 — 기본 경로 미채택

`fpstudio-vkmatch --scale-refinement`를 명시한 경우에만 algorithm_version4를
출력한다. 기본 경로는v3다. 내부 근거가 약한 정렬의 상위6개 기준/전처리 조합에
배율0.85~1.15(0.025간격), 각도/이동±2를 추가 탐색한다. 동일 내부 기준으로
검증하며 기존보다 약한 결과는 기존 정렬을 유지한다.

합성0.875/1.125배 영상 복원 및 무정보/독립 잡음 반례를 시험했다.
고정 기준25장으로 기존43장과 최신33장을 재검사했으나 v3 대비 추가 회복은0장이다.
최신33장은32장/29접촉 중28접촉 일관성으로 동일했고, 이전43장은36장/30접촉 중
25접촉으로v3와 같았다. 따라서 이 탐색은 오프라인 실험 옵션으로만 남긴다.
첫 세션의 원본 gpu-match는v2이므로 단순 원본 대비 개선1장은v3의 회전 효과이며
배율 탐색의 개선으로 보고하지 않는다. 임계값은 변경하지 않았다.

재현 가능한 평가 도구:

```bash
python tools/vkmatch/evaluate.py \
  --matcher src/fpstudio/build/fpstudio-vkmatch \
  --reference-dir /absolute/prior-session \
  --session /absolute/probe-session \
  --prefix unique-experiment --scale-refinement
```

기존 원본/결과는 덮어쓰지 않는다. 결과는 지정한 로컬 세션에0600으로 저장된다.
원본 비교와 before_scale 비교를 구분하며, 반복 개발 자료를 독립 인증률로
보고하지 않는다. 실제 다른 손가락 거절 데이터는 여전히 없다.

## 시스템 인증 경계

이번 변경은 연구 앱과 로컬 GPU 실행 파일뿐이다. PAM, fprintd, 설치된 시스템
libfprint 및 사용자 등록 템플릿은 변경하지 않는다. 지문 인증의 안전성을
입증하지 못한 영상 유사도를 sudo/polkit 승인으로 연결하지 않는다.
