# FPStudio v0.2.5

This release supersedes the v0.2.4 source release with a CI-completeness fix.
No product behavior, driver patch or distributed content changed.

## Release fix

- The translation-validation job now installs `qt6-declarative`, the runtime
  dependency required by the Arch `lupdate` binary, before verifying that all
  eleven catalogues are current and complete.

## Delivery guarantees

- CI checks source hygiene, driver reproducibility, build/test results,
  Vulkan/CPU score parity and translation completeness.
- The release workflow rebuilds and tests the tagged source before producing
  the source archive and SHA-256 checksum.
- No firmware, biometric data, templates, credentials or user account data are
  in the release assets.
