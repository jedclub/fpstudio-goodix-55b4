# FPStudio v0.2.1

This public release supersedes the initial v0.2.0 tag, whose GitHub release
verification found a CI-only Lavapipe ICD-path assumption before any release
asset was published.

## Release fixes

- Discover the installed Lavapipe ICD manifest at runtime in both CI and the
  release workflow, then run the full Vulkan/CPU parity and research tests.
- Verify the complete 19-patch Goodix driver series against the pinned
  libfprint revision and make repeated `makepkg` attempts reset their generated
  source checkout before applying patches.

## Included product work

- Guided local capture and colour-coded, Vulkan-assisted v8 contact-anchored
  ridge comparison.
- Eleven-language UI catalogues, source-only distribution, LGPL-2.1-or-later
  licensing and third-party notices.
- No firmware, biometric data, templates, credentials or user account data.

## Verification

The tagged source must pass the full CTest suite under software Vulkan before
the workflow creates the source archive, SHA-256 checksum and GitHub release.
