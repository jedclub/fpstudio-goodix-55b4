# FPStudio v0.2.9

Self-contained Release packaging and a consistent guided setup path for the
Goodix 27c6:55b4 driver, GPU matcher and simultaneous local authentication.

## Changes

- Install the GUI, translations, driver recipe, setup helpers, Vulkan matcher,
  PAM module and sensor worker as one relocatable wizard support bundle.
- Make installed setup checks resolve only executable-relative resources; no
  source checkout or developer home path is embedded in Release binaries.
- Detect only the current fail-closed simultaneous PAM policy. Legacy
  `sufficient` configurations are reported as needing repair instead of being
  mistaken for a complete installation.
- Remove obsolete hand-installable sudo, Polkit and KDE PAM templates so a
  source checkout cannot accidentally reintroduce the former serial path.
- Complete Qt translation routing for setup, recovery, frame-quality and live
  capture messages. Korean is complete; untranslated new strings in other
  catalogues fall back to English.
- Keep private research sessions in the user's XDG data directory and exclude
  biometric samples, credentials, backups and agent metadata from releases.
- Reduce CPU work in frame selection and libfprint device discovery while
  preserving the persistent Vulkan batch matcher for the expensive bounded
  rotation and ±5% scale search.
- Add privacy-safe PAM transport diagnostics without logging passwords,
  usernames, biometric images or template paths.
- Make KDE Plasma 6.7 lock-screen fingerprint status visible through the
  non-interactive channel its shipped QML actually renders. The label now
  reports sensor start, readiness, contact, animated checking, retry count and
  explicitly directs password entry after timeout or device failure.
- Allow the sensor worker enough graceful-cancellation time to complete both
  fprintd `VerifyStop` and `Release`, preventing an interrupted prompt from
  leaving the device permanently claimed until the daemon restarts.
- Honour Plasma/gettext `LANGUAGE` preferences, including lists such as
  `ko:en`, while preserving the standard locale-variable precedence for all
  eleven PAM feedback catalogues.
- Add searchable GitHub project metadata, a privacy-safe contribution path,
  structured issue forms, a security policy and a 1280x640 social-preview
  asset.
- Publish the tested Arch Linux x86-64 application bundle beside the source
  archive on tagged releases, with both artifacts covered by SHA-256 checksums.

## Verification

- Release build uses CMake `-O3`, interprocedural optimisation/LTO and source
  path remapping.
- Setup policy, fail-closed PAM, ridge ROI, minutiae controls, localisation,
  argument-boundary and authentication log tests pass.
- Fourteen synthetic simultaneous-PAM scenarios, thirteen PTY input scenarios,
  ten worker-bus scenarios, locale precedence and the Python installer/report
  suites pass.
- The staged install contains no fingerprint images, enrolments, credentials,
  local research directories or developer home paths.

## Upgrade notes

- Run the integrated setup wizard after installation. Old serial
  `pam_fprintd sufficient` profiles are intentionally not considered current.
- Existing GPU references and fprintd enrolments are preserved by matcher-only
  refreshes. PAM changes remain transactional and recoverable from the backup
  recorded by the installer.
- Biometric matching remains experimental. Verify both fingerprint success and
  password recovery on the actual machine before relying on it.
