# FPStudio v0.2.4

This public release supersedes the unissued v0.2.0 through v0.2.3 verification
tags. Their GitHub verification stopped before an asset could be published.

## Release fixes

- CI locates the installed Lavapipe manifest and explicitly opts into a Vulkan
  CPU device only for software-Vulkan shader/CPU-parity coverage. Normal
  FPStudio execution still selects discrete or integrated graphics hardware.
- Gradient correlation now requires meaningful energy in both images before
  dividing. This rejects flat-frame reduction noise consistently in the GPU
  shader and CPU reference path, and is covered by a texture-versus-flat test.
- The full CTest suite must pass before the workflow creates the source
  archive, SHA-256 checksum and GitHub release.

## Included product work

- Guided local capture and colour-coded, Vulkan-assisted v8 contact-anchored
  ridge comparison.
- Eleven-language UI catalogues, source-only distribution, LGPL-2.1-or-later
  licensing and third-party notices.
- No firmware, biometric data, templates, credentials or user account data.
