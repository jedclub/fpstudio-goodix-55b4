# FPStudio v0.2.0

First public release of FPStudio for the Goodix 27c6:55b4 fingerprint reader.

## Highlights

- Guided setup wizard for the patched Goodix/libfprint driver, permissions,
  enrolment, and opt-in authentication configuration.
- Live, privacy-local fingerprint research capture with automatic candidate
  selection and a colour-coded comparison preview.
- Vulkan-assisted contact-anchored ridge comparison with bounded rotation and
  ±5% uniform-scale search for research evaluation.
- Eleven-language UI catalogues and a remembered language preference.
- Password fallback is retained for system authentication. GPU matching and
  system-authentication integration remain explicitly experimental.

## Distribution and privacy

- This release contains source, build recipes, patches and documentation only;
  no firmware blobs, fingerprints, templates, device secrets or account data
  are included.
- The driver source revision is pinned to
  `c1937b99ec3db5abca05f619a95d2e37496d8810` for reproducible builds.
- FPStudio and driver patches are LGPL-2.1-or-later. See [LICENSE](../../LICENSE)
  and [THIRD_PARTY_NOTICES.md](../../THIRD_PARTY_NOTICES.md).

## Verification

The release build completed the full CTest suite, including setup-policy,
research-workflow, ridge ROI, minutiae, authentication-search and Vulkan/CPU
parity tests.
