# FPStudio v0.2.7

Improved interactive Goodix authentication feedback and resilient GPU matching.

## Changes

- Show live, privacy-safe finger contact feedback in supported PAM dialogs:
  touch detection, a compact braille-dot scan spinner, retry count and result.
  No raw fingerprint image is exposed in administrator or lock-screen prompts.
- Update sudo and TTY feedback in place rather than appending spinner lines.
  Keyboard input still takes priority and remains masked.
- Forward fprintd `finger-present` transitions through the isolated sensor
  worker to GUI and terminal clients. Transient completed errors are reset and
  retried within the existing 20-attempt bound.
- Keep GPU matching first. On a GPU helper failure, discard the failed helper,
  create a fresh Vulkan helper/context, and retry GPU matching once. A definite
  no-match is not retried; a second failure safely falls back to SIGFM.
- Relax the driver’s pre-match partial-contact gate from 62% to 45% coverage.
  The final GPU/SIGFM identity acceptance thresholds are unchanged.
- Remove the temporary fprintd debug override after diagnosis so verbose
  transport diagnostics are not retained.

## Verification

- PAM localisation, simultaneous authentication and terminal masking tests.
- Private D-Bus worker tests, including contact transitions, dot-spinner
  progress and bounded transient-error recovery.
- libfprint `fpi-assembling`, `fpi-ssm` and `fpi-device` tests.
- Local hardware verification observed `finger-present`, dot-spinner updates,
  GPU matching and successful Polkit authentication.

## Notes

- This remains experimental biometric authentication; retain password access.
- The GUI animation is state feedback only. Raw fingerprints remain available
  solely in the explicit local diagnostic workflow, never in PAM prompts.
