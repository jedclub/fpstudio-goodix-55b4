# 기준 데이터 선별과 단계적 GPU 탐색

## 데이터 분리

- 기준 후보: `live-20260907-011121-680`의25장
- 기준 선별용 개발 자료: `live-20260907-012905-471`의v3 비교43장/추정30접촉
- 별도 수집 재평가 자료: `live-20260907-022144-330`의73장/추정70접촉
- 접촉 감지 실패가 사용자 확인된 `live-20260907-020714-076`은 선별에서 제외

`tools/vkmatch/prepare_bank.py`는 선별용 자료의 내부 무늬 일치와 정렬 모호함을
이용해 접촉 범위를 덮는 대표 기준을 고른다. 재평가 세션은 이 도구에 입력하지
않는다. 지문 라벨은 사용자 확인 자료를 사용하며 UI의 instructed_role로 추정하지 않는다.
원본은 유지하고 별도의0700 폴더에0600 이미지와 해시/출처 manifest를 만든다.
현재 등록 템플릿이나 fprintd 저장소를 덮어쓰지 않는다.

## 선별만 적용했을 때의 실패

이전 자료에서2장이25/30접촉을 덮었지만, 별도 수집73장에서는62장/70접촉 중
60접촉만 내부 일관성 기준을 충족했다. 기존25장 기준의73/73,70/70보다
나빠졌으므로 **전체 기준을2장으로 교체하는 변경은 채택하지 않았다.**

## 단계적 탐색v5

전체25장을 유지하며 `--fast-reference-bank`를 지정할 때만 적용한다.

1. 선별된 대표 기준으로 먼저 탐색한다.
2. 내부 일관성, 내부 방향 상관≥0.65, 모호하지 않은 정렬, 탐색 경계 아님을
   모두 만족할 때만 이 연구 결과를 반환한다.
3. 그 외에는 기존 전체 기준으로 동일한v3/v4 탐색을 수행한다.

새로운 인증 임계값을 낮추지 않는다. 결과는 여전히 research_only이며
authentication_decision은null이다. 파일 해시로 대표 기준이 전체 기준의
중복 없는 부분집합인지 검증하고, manifest 손상·경로 이탈·심볼릭 링크를 거부한다.

동일73장 재실행에서73장/70접촉 모두 내부 일관성이 유지됐으며33건에서
전체 기준 탐색을 사용했다. 초기 측정 평균181ms였지만 다른 작업/장치 상태가
성능에 영향을 줄 수 있으므로 이전284ms와 엄격한 통제 실험으로 해석하지 않는다.
대표 기준 선택은 별도 자료로 했지만, 단계적 탐색 설계에는 축소 실험의 실패를
참고했으므로 이 세션을 최종 독립 인증 성능 평가로 주장하지 않는다.

기존 SIGFM 참조 재구현도 같은25기준/73검사 영상으로 평가했다:
원본49/73, 중복 제거 수정54/73, 각도 수정54/73, Lowe 비율0.8 실험62/73.
비율 완화는 실제 다른 손가락 자료가 없어 시스템에 적용하지 않았다.
SIGFM의점수72 통과와 GPU 내부 일관성 기준은 서로 다른 판정 기준으로,
이 숫자 차이만으로 보안 수준이나 실제 sudo 인증률을 비교할 수는 없다.

## 실행과 자동 종료

```bash
fpstudio --live --lang ko --match-reference-dir /absolute/full-reference-session \
  --match-fast-bank /absolute/curated-bank --target-contacts 20
```

기준을 지정한 GUI의 기본 목표는 비교 완료20접촉, 다른 손가락 시험은10접촉이다.
`--target-contacts 0`은3분 동안의 기존 연속 연구 모드다. 목표에 도달하면
자동으로 수집을 멈추고 추가 대기 후보는 target-reached로 기록한다.
품질 부족으로 비교되지 않은 접촉은 비교 완료 횟수에 넣지 않는다. 어떤 경우든
기존3분 제한과 사용자 중단 버튼을 유지한다.

실제 시스템 인증 연동과 다른 손가락 거절 검증은 별도 단계이며, 이 연구
갤러리나 표식 설치만으로 sudo가 새 알고리즘을 사용하게 되지는 않는다.

## 추가 수집과 사용자 라벨 확인

`live-20260907-024410-474`는 USB I/O 오류로 캡처 전에 종료됐다. 해당 센서만
USB reset한 뒤 `live-20260907-024540-701`에서10접촉/12비교를 완료하고
목표 도달로 자동 종료됐다. 전부 내부 무늬 일관성을 충족했다.

창에는 다른 손가락 시험 안내가 있었지만 사용자는 이후
"지금 계속 같은 손가락만 사용중"이라고 확인했다. 따라서 실제 라벨은
**같은 손가락**이며 각 세션의user-label.json에 정정했다. 원본의
instructed_role는 보존하며 오인식 자료로 해석하지 않는다. 실제 다른
손가락 거절 성능은 아직 검증하지 못했다.

자동 종료 시 작업자kill을 QProcess가Crashed로 보고해 "GPU 비교를 실행할 수
없습니다"라고 표시하는 UI 오류도 발견했다. 비교12건은 이미 저장됐고
실행 중 오류는0건이었다. 목표 완료는 표준입력 종료로 정상 종료하고,
사용자 중단으로 의도적으로kill한 경우는 취소로 분리한다. 실제 실행 실패와
비정상 종료는 계속 오류로 표시한다. 비동기 종료 신호까지 기다려 자동 완료·
사용자 중단·실제 실행 불가를 구분하는 회귀 시험을 추가했다.
