# 관리자 인증 안내 표식

`[Admin 인증] %s 관리자 권한 요청`을 sudo/polkit 지문 인증 직전에 PAM
정보 메시지로 표시한다. `%s`는 PAM 서비스 이름(sudo 또는 polkit-1)이다.
일반 연구·등록 화면에 관리자 인증이라고 표시하지 않는다.

관리자 표식은 동시입력 PAM 모듈이 locale에 맞게 직접 표시한다. 표식의
성공/실패는 인증 허용·거절 판단과 분리되어 있다. 현재 시스템 인증은 별도의
보호된 동시입력 모듈을 사용하며 실패 접촉 최대 20회 또는 60초로 제한한다.
모듈 내부 오류는 인증 성공으로 처리하지 않고, 뒤의 `system-auth` 비밀번호
경로를 확인하고 보존한다. 시간 제한은 손가락 감지가 없을
때 55x4 센서의 과열 보호가 인증을 중단하는 일을 방지한다. 관리자 표식 자체가
요청의 진위를 보증하지는 않는다. 사용자 자신이 시작한 작업인지 확인해야 한다.

일반 sudo 암호 프롬프트를 바꾸는 sudo -p/SUDO_PROMPT 설정과 다르다.
터미널에는 PAM 정보 메시지로 전달되며, polkit의 표시 형태는 데스크톱
인증 에이전트에 달려 있다. 매 재시도 문구나 창 제목을 모두 변경하는 것은 아니다.

기존 시스템 구성의 변경안 확인(읽기 전용):

```bash
python tools/dual_auth_install.py
```

실제 적용은 root 권한이 필요하다. 이 스크립트는 자체적으로 sudo를 실행하거나
인증창을 띄우지 않는다. 사용자가 적용할 경우:

```bash
sudo python tools/dual_auth_install.py --apply
```

지원하는 root 소유 설정만 처리하고, 숫자 점프·중복 지문 모듈·불명확한
사용자 정의 스택은 수정하지 않는다. 변경 전 원본은
`/var/backups/fpstudio-dual-auth/`의 실행별 0700 폴더에 0600으로 보관한다.
sudo, polkit, 로컬 TTY 로그인, su/su-l 및 KDE 지문 서비스를 한 트랜잭션으로
검사하며 KDE의 별도 비밀번호 서비스가 확인되지 않으면 적용을 거부한다.

기본 실행은 항상 읽기 전용 미리보기다. 실제 적용 뒤에는 `sudo`·polkit에서
지문 성공뿐 아니라 시간 초과 뒤 비밀번호 입력도 별도로 확인해야 한다. 설정
파일의 존재나 helper 자기 비교만으로 실제 인증 성공을 주장하지 않는다.

이 표식 작업은 Vulkan 연구 매처의 PAM 연동이 아니다. 연구 세션의 영상은
로컬 비공개 자료이고, 기존 시스템 fprintd 등록 템플릿을 자동으로 교체하거나
학습시키지 않는다. 데이터 수집, 매칭 실험, 시스템 인증 적용은 구분한다.
