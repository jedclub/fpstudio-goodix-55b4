# Vulkan 병렬 영상 매칭 연구

## 구현 범위

`tools/vkmatch`는 실제 Vulkan 컴퓨트 셰이더로 여러 영상·정렬 조건을 일괄 비교한다.
CPU/소프트웨어 Vulkan 장치를 GPU로 보고하지 않으며 지원 GPU가 없으면 명시적으로 실패한다.
현재 AMD Radeon Graphics (RADV RENOIR)에서 빌드와 실행을 검증했다.
기존 SIGFM, fprintd, PAM 및 등록 템플릿은 변경하지 않는다.

이 모듈은 **영상 정렬과 유사도 탐색기**다. 검증된 지문 신원 판정기나
학습된 모델이 아니며 결과 JSON의 `authentication_decision`은 항상 null이다.

## 계산 흐름

1. 기준 1~64장과 검사 영상을 108×88 회색조로 읽는다.
2. 원본 및 국소 명암 정규화 두 경로를 만든다. 정규화는 11×11 상자창의
   평균·표준편차와 명암 하한을 사용하며 원본을 덮어쓰지 않는다.
3. GPU에서 기준별 회전 -30~30도(5도 간격), x/y 이동 -24~24px(4px 간격)를
   4px 샘플 간격으로 탐색한다.
4. 각 기준/전처리의 서로 떨어진 상위 정렬 3개 주변에서 각도±2도,
   x/y±2px(각1 간격), 배율0.97/1.00/1.03을 2px 샘플 간격으로 재탐색한다.
5. 부호 있는 명암 NCC, 회전 보정한 그래디언트 상관, 유효 겹침, 평균 절대
   명암 차이(MAE)를 동시에 계산한다. 픽셀 값과 양선형 보간의 CPU 참조 구현도 제공한다.

정렬 하나를 128개 셰이더 invocation이 분담하며, 2,048개 정렬씩 잘라
제출한다. 이미지와 작업 버퍼를 재사용한다. 비일관 메모리의 flush/invalidate,
CPU/GPU 메모리 장벽, 완료 fence 및 GPU 타임스탬프를 사용한다.

탐색 순위는 `0.65*NCC + 0.35*gradient - 0.15*(1-overlap) - 0.1*MAE`다.
겹침0.55 미만은 순위에서 제외한다. 이 가중치와 한계는 연구용 초기값이며
인증 임계값이 아니다. 독립적인 다른 정렬과 점수 차이가0.02 미만이거나
독립 정렬을 찾지 못하면 `ambiguous`를 표시한다. 최고 정렬이 탐색 경계에
가까운지도 보고한다. 평행 줄무늬, 센서의 고정 무늬, 잘못된 배경 차감은
높은 점수를 만들 수 있다. 이웃 프레임/동일 데이터의 복제는 독립 검증 자료가 아니다.

## 빌드 및 오프라인 실행

Qt6, Vulkan 개발 파일, `glslangValidator`가 필요하다. 기존 fpstudio 빌드가
셰이더와 `fpstudio-vkmatch` 실행 파일을 함께 만든다.

```bash
cmake -S src/fpstudio -B src/fpstudio/build -DBUILD_TESTING=ON
cmake --build src/fpstudio/build -j 4
src/fpstudio/build/fpstudio-vkmatch \
  --reference /absolute/path/reference.png \
  --reference /absolute/path/another-reference.png \
  --probe /absolute/path/separate-probe.png
```

`--probe`도 최대64개까지 반복 가능하다. 기준 폴더의
`candidate-touch-*.png`, `reference-index-*.png`는 `--reference-dir DIR`로 읽는다.
출력은 probe당 JSON 한 줄이다. 동일한 실제 파일을 reference/probe로
동시에 지정하면 거부하지만 복제된 동일 내용까지 독립성을 증명해 주지는 않는다.

`--serve`는 기준 목록과 Vulkan 파이프라인을 유지하는 로컬 stdio 작업자다.
준비 JSON 후 `{"probe":"/absolute/path/probe.png"}` 한 줄마다 결과 한 줄을
반환한다. 네트워크 서버나 외부 전송 기능은 없다.

## 실시간 창 연결

```bash
LD_LIBRARY_PATH="$PWD/src/driver/src/libfprint-goodixtls-55x4/build/libfprint" \
  src/fpstudio/build/fpstudio --live --lang ko \
  --match-reference-dir /absolute/path/prior-session
```

새로 선별된 안정 후보를 별도 Vulkan 작업자에 보낸다. UI와 캡처는 기다리지
않으며 한 번에 한 요청만 허용한다. 계산·초기화 중에는 **접촉별 최신 최고 후보
한 장**을 보관하고 준비되는 대로 접촉 순서로 처리한다. 인접 프레임 전체를 쌓지 않는다.
이는 모든 프레임의 전체 탐색을 보장하는 방식이 아니라, 연속 미리보기를
유지하면서 선별 영상에 무거운 탐색을 적용하는 방식이다.

화면에는 조건 수, 전처리·업로드·결과 정리를 포함한 요청 시간, 최상위 기준,
NCC, 방향 일치, 정렬 모호함과 경계 경고를 표시한다. 중단 외 버튼은 없다.
30초 초기화/계산 제한, 최대128접촉 후보 저장, 접촉당3회·세션당384회 비교
저장 한도가 있다. 한도·오류·사용자 중단으로 비교하지 못한 사유도 기록한다. GPU 오류는 캡처를
멈추거나 CPU 결과를 GPU 결과로 표시하지 않는다.

`local-private/recognition/live-날짜/`의 `gpu-probe-NNNN.png`는 각 요청 당시의
불변 검사 영상, `gpu-match-NNNN.json`은 점수·검사 경로·접촉 그룹·센서
타임스탬프를 보존한다. 폴더0700/파일0600이며 Git에서 제외된다.

## v2: 내부 영역 검증 및 제한적 경계 확장

`algorithm_version: 2`는 GPU 상위 정렬 후보에 CPU 내부 영역 검증을 추가한다.
원본 영상 양쪽의 바깥8px를 제외하고, 기준 영상을4×4 영역으로 나누어 국소
명암 상관과 회전 보정한 그래디언트 일치를 함께 확인한다. 픽셀 겹침과
지지 영역 수를 `interior`에 별도로 출력한다. 이 검사는 GPU 탐색의 대체가
아니라 서로 다른 상위 정렬3개의 후속 검사다.

`consistent`는 연구용 초기 기준이다: 내부 겹침≥0.4, NCC≥0.55,
그래디언트 상관≥0.5, 지지 영역≥4, 검사 영상의 대응 영역≥4,
지지 영역이 유효 영역의 절반 이상. 영역별 지지는 NCC≥0.5 및
그래디언트 상관≥0.45를 요구한다. 전체 NCC 하나만 높은 경우와 구분하기
위한 기준이며 일반적인 생체 인증 통과 기준으로 검증된 값이 아니다.
전체 순위는 GPU 순위와 내부 NCC/그래디언트의 작은 값, 내부 겹침을 함께
사용한다. 따라서 기존 GPU 순위1위와 최종 후보가 달라질 수 있다.

기존 범위 끝에 걸린 기준/전처리 그룹만 현재 최고 정렬의 각도·이동
±8 범위를4 간격으로 추가 탐색한다. 최대 이동±36px, 각도±40도에서
제한하며 `extension_hypotheses`, `search_extended`로 명시한다.
경계 표시 감소 자체가 인식률 향상을 뜻하지는 않는다.

2026-09-07 저장 검사 영상48장에 같은 기준9장을 유지하고 재실행:
내부 무늬 일관성40장, 근거 부족8장, 모호한 정렬9장, 확장 후 경계2장,
평균 요청95.96ms. 이 자료는 파라미터 개발에도 사용했으므로 독립 평가가 아니다.
사용자는 이48장이 수집된 세션에서 한 손가락만 사용했다고 확인했다.
실제 다른 손가락 거절률은 아직 측정하지 않았다.

새 `--different-finger-test` 옵션은 실시간 창에 이전과 **다른 손가락**을
사용하도록 지속 안내하며 각 GPU 결과에 `instructed_role: different-finger`를
기록한다. 지시가 실제 수행됐다는 자동 증명은 아니므로 사용자 확인이 필요하다.
기준 폴더는 한 손가락만 사용했다고 확인된 이전 세션을 지정한다.
어떤 연구 결과도 시스템 등록이나 인증 판정에 자동 반영하지 않는다.

회귀 시험에는 내부 무늬 동일 영상과, 테두리만 같고 내부는 독립 잡음인
반례가 추가됐다. 후자는 내부 일관성 근거로 인정하지 않아야 한다.

## v3: 조건부 360도 회전 탐색

`algorithm_version: 3`은 v2의 빠른 탐색 결과가 내부 일관성 미달,
내부 그래디언트 상관0.65 미만 또는 정렬 모호함인 경우에만 전체 회전을
추가 탐색한다. 기존의 내부 일관성 기준은 낮추지 않는다.

- 넓은 탐색: -180~170도(10도 간격), 이동±24px(8px 간격), GPU 샘플 stride4
- 기준/전처리별 상위2개 정렬: 각도±5도(1도 간격), 이동±4px(2px 간격),
  배율0.97/1/1.03, stride2로 정밀 탐색
- 각 그룹 최고 정렬 주변: 각도/이동±1(0.5 간격)의 마지막 정밀 탐색
- 각도 차이는360도 원형 거리로 계산해179도와-179도를 같은 부근으로 취급

추가 후보도 동일한 내부 영역 검사로 확인한다. 기존보다 내부 근거가 약해지거나
기존의 일관성 있음 결과가 일관성 없음으로 바뀌면 기존 후보를 유지한다.
`wide_rotation`, `rotation_hypotheses`, `fast_best`로 적용 여부와 이전 후보를
감사할 수 있다. 화면에는360도 추가 탐색 적용 여부가 표시된다.
넓은 탐색은 전체 공간의 모든 실수 각도/이동을 보장하는 완전 탐색이 아니라
이산 격자와 후보 가지치기를 사용한다.

### 실제 저장 자료 재검사

사용자가 같은 손가락으로 확인한 세션의43개 검사 영상을, 이전 세션의
같은 손가락 후보25장을 기준으로 재검사했다. 원본 영상과 기준 목록은 유지했다.

- v2: 내부 일관성35/43 영상,24/30 추정 접촉 그룹
- v3: 내부 일관성36/43 영상,25/30 추정 접촉 그룹
- 9개 검사에서360도 추가 탐색 적용. 추가로 회복된 그룹의 정렬은51도
- 기존에 일관성이 있었던 검사의 퇴행은 관측되지 않음
- 약70도 후보가 발견됐어도 내부 근거가 부족한 영상은 그대로 미달 처리

이 자료는 개발 중 반복 사용한 자료이며 독립적인 인증 성공률 평가가 아니다.
사용자는 "다른 손가락 시험" 안내가 나온 뒤에도 한 손가락만 사용했다고
확인했다. 해당 세션의 `user-label.json`을 실제 라벨로 사용하며 원본의
`instructed_role`을 실제 다른 손가락 데이터라고 해석하지 않는다.

이번 실행에서 빠른 경로 평균564ms, 추가 탐색 경로 평균1,002ms였다.
동일 프로세스 반복 측정에서는 빠른 경로561ms, 추가 탐색1,280/1,294ms가
측정됐다. 기준25장에 대한 이번 장치 상태의 값이며 초기9장 시험의 시간과
혼동하지 않는다. 실시간 프레임 표시와 매칭 요청은 여전히 별도 프로세스이고
추가 계산 중 프레임을 대기열에 쌓지 않는다.

자동 통합 시험에0도(빠른 경로),90도,180도,-175도 합성 영상의
최종 정렬 오차≤2도, 내부 일관성, 신원 판정null을 추가했다.
